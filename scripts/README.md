# Script Index

The supported Chikooza launchers and their setup documentation are grouped in
`scripts/launchers/`:

- `launchers/QUICKSTART.md` provides the short command list.
- `launchers/README.md` is the complete local and Ubuntu server setup guide.
- `launchers/local.sh` runs local setup and development on Linux, macOS, or
  Windows Git Bash.
- `launchers/local-windows.cmd` forwards Windows Command Prompt or PowerShell
  commands through Git Bash.
- `launchers/server-linux.sh` deploys to an Ubuntu 24.04 production server.
- `launchers/server.env.example` is the production server configuration
  template.

The other files directly under `scripts/` are older workflows retained for
compatibility and historical reference. Do not use them for a new local setup
or production deployment.
